# allRating

Two implementations live here:

- **all-rating**, a dependency-free, form-associated web component. See [README-web-component.md](README-web-component.md) and the [live demo](web-component.html).
- **The original allRating jQuery plugin**, unchanged in js/jquery.allRating.js with its demo in index.html.

## GitHub Pages

The repository is served as a static site from the master branch root, so the published URLs are:

- web-component.html, the new component demo
- index.html, the original jQuery demo
- tests/web-component.html, the browser integration tests, which report PASS/FAIL on the page
