# allRating

Two implementations live here:

- **all-rating**, a dependency-free, form-associated web component. See [README.md](README.md) for the API, styling and migration notes, and the [live demo](web-component.html).
- **The original allRating jQuery plugin**, unchanged in js/jquery.allRating.js with its demo in index.html.

## GitHub Pages

Once Pages is enabled for this repository (Settings, Pages, deploy from branch, master, root), the published URLs are:

- https://squidjam.github.io/allRating/web-component.html, the new component demo
- https://squidjam.github.io/allRating/, the original jQuery demo
- https://squidjam.github.io/allRating/tests/web-component.html, the browser integration tests, which report PASS/FAIL on the page
