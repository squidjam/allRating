allRating, without jQuery

A native, form-associated web component. Use the mouse, touch, or keyboard. Arrow keys choose a rating; Home/End choose the first/last; Delete clears.

<script type="module" src="js/all-rating.js"></script>
<all-rating name="rating" value="3" aria-label="Your rating"></all-rating>
Choose ratings, then submit.

The original jQuery demo remains at index.html.
