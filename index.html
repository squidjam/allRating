allRating web component

A native, form-associated rating control. No jQuery, no images, no build step. Try each control with a mouse or with the keyboard: arrow keys select, Home and End jump, Delete clears.

FormData

Choose ratings, then submit.

Tag reference

AttributeMeaning
valueDefault rating; reset restores it
maxScale size, 1–100 (default 5)
nameKey used in form submission
themestar, tinystar, bar, or medal
requiredRejects a zero rating on submit
disabled, readonlyBlock editing; disabled also blocks submission
labelsJSON array of text for each rating, index 0 included
aria-labelAccessible name when no visible label is associated

User input fires input then change events. The untouched jQuery plugin demo is still here, and the README covers the API and migration notes.
